WebAuditJ 出力レポート例

合成アクセスログから生成したサンプルです。資料一覧から、幹部向けの判断資料、技術者向けの確認・対応手順、不審アクセスのログ一覧、追加調査の依頼文を開けます。

日本語

  • 資料一覧から読む
  • 幹部向けレポート
  • 技術者向けレポート
  • 不審アクセスのログ一覧（CSV）

English

Reports generated from synthetic access logs. Start with the artifact index, or open a report directly.

  • Artifact index
  • Executive report
  • Technical report
  • Suspicious access logs (CSV)

単一ファイルの出力例

  • HTMLレポート · JSON · CSV
  • GeoIP・ASN付きHTMLレポート

サンプルの検出は侵害の成立を示すものではありません。判定の根拠と、追加確認が必要な証拠を各レポートで確認してください。
