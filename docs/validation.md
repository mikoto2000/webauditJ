## 回帰テスト

Windows 11 / OpenJDK 25 (`25+36-3489`) で **2,807 テスト成功、失敗・エラー・スキップ 0**。

Ubuntu 24.04 (WSL2) / OpenJDK 25.0.5.1 でも **2,807 テスト成功、失敗・エラー・スキップ 0**。Linux の `mvnw verify` で生成した同じ JAR を Windows の `java -jar` でも実行し、サンプルの 9 リクエスト・4 事案、未解析 0、部分解析なしを確認しました。

期待値は基準版を archive したソースで生成し、通常の Java テストでは Go を起動しません。再生成ツールも同梱しています。再生成の比較では parser/detection/corpus がバイト単位で一致し、upstream は集合として扱う警告の列挙順だけが変わることを確認しました。

| 保存済み Go 参照値 | ケース数 | 比較対象 |
|---|---:|---|
| parser | 1,321 | 受理/拒否、受理した 1,042 件の Event 全体 |
| detection | 1,042 | シグネチャ ID と正規化結果全体 |
| upstream | 107 | Hub/Aura と解析レポート全体 |
| corpus | 71 | nonce・時刻・反復間隔を再現した解析レポート全体 |

件数はテスト数と一対一ではありません。比較で除くのは実行日時・入力の絶対パス・実装バージョン・警告順です。タイムゾーン不明時の事案 ID は入力の絶対パスに依存するため、別の関連付けテストで分離を確認します。通常の事案 ID、観測順、件数、証拠、スコア、成否理由は比較に含めます。参照値の SHA-256 は [baseline.json](reference/baseline.json) にあります。

追加テストは、UTF-8 バイト単位の制限、不正な percent 復号候補、Go の空白定義、時刻の競合、二重窓、ロバスト統計、行動検知、Hub 状態遷移、gzip の CRC/連結メンバー/末尾破損、巨大行後の回復、重複ファイル、上限時の部分解析を対象にしています。

GeoIP は公開/非公開 IP、IPv4-mapped IPv6、各検索状態、スキーマ不整合、未収録を含む LRU、表示サンプルと独立した件数、ASN 相関を確認しました。DB 管理はサイズ上限・期限・redirect 許可・チェックサム・全レコード検証、段階別失敗注入、二つ目の DB 取得失敗、別 JVM 間のロック、強制終了からの復旧、破損した現世代からの rollback を検証しています。

CLI/出力は終了コード、出力先上書き拒否、HTML エスケープ、CSV 数式抑止、制御文字除去、JSON の null と省略の区別を確認しています。

## 性能測定の読み方

10 万行の実測値です。元データは [performance-windows.json](measurements/performance-windows.json)。メモリ値は MiB に換算しています。

| IP ケース | GeoIP | DB open + 解析 (秒) | ヒープ観測最大 (MiB) | プロセスメモリ観測最大 (MiB) | 部分解析 |
|---|---|---:|---:|---:|---|
| 反復 | 無効 | 69.54 | 43.5 | 149.5 | いいえ |
| 反復 | 有効 | 66.50 | 92.2 | 209.8 | いいえ |
| 異なる IP | 無効 | 70.35 | 78.0 | 174.6 | はい |
| 異なる IP | 有効 | 72.25 | 112.5 | 233.0 | はい |

有効時の DB オープンは反復ケース 4.78 秒、異なる IP のケース 4.64 秒。反復ケースの reader lookup は 4 回、peer cache hit は 99,998 回でした。GeoIP の有無で検知ハッシュは各ケースとも一致しました。有効時に短くなった単発値から高速化を結論づけることはできません。

測定は Windows 11、24 論理 CPU、OpenJDK 25、`-Xms64m -Xmx512m`。各ケースは単発の別 JVM です。入力生成/JVM 起動を除き、DB オープンと最初のクラス初期化・JIT を含む解析を測ります。DB は上記の実配布版を Windows の MEMORY モードで読み込みます。マシンの他プロセス・OS キャッシュは制御していません。

反復ケースは二つの公開 IP（IPv4/IPv6）、異なる IP のケースは 10 万 IP の混合入力です。異なる IP のケースは既定 `max-keys=4096` に達し、部分解析として終了します。この値は全 IP の完全解析性能ではありません。GeoIP 有効/無効で検知フィールドのハッシュが一致することも測定ツールで確認します。

ヒープは約 10ms 間隔の使用量、プロセスメモリは約 50ms 間隔の観測値です。上限・生存オブジェクト量・瞬間ピークとは区別してください。Go の既存の単発測定とは条件が異なるため、速度比は算出していません。初期版に数値の性能合格基準は設定していません。
