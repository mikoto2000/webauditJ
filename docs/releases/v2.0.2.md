# WebAuditJ v2.0.2

Go版の分析高速化をJavaへ移植したパッチリリースです。

## 変更点

- Aura署名・独自ルール・上流データの正規表現を必須文字列で事前選別します。最終判定はRE2/Jのままです。Unicode入力・不正なUTF-16サロゲート・未対応の構文は直接RE2/Jで評価します。
- フィールド変換をルール間で共有し、固定リストの大文字化を初期化時に行います。
- オンラインの中央値・MAD計算で128要素の作業領域を再利用し、観測順序と統計閾値を維持します。
- 全同梱正規表現の判定比較、統計計算の一致テスト、実JARの性能・全レポート比較ツールと生データを追加しました。

Windows 11 / JDK 25で前後交互に各3回測定した中央値の速度比は、通常1万行で3.41倍、長いUA 1000行で23.63倍、攻撃20%混在1万行で3.61倍でした。全18回で条件ごとの全レポートハッシュが一致しました。長いUA条件は既存のサンプル切り詰めにより前後とも部分解析です。

詳細な条件・結果は[分析処理の高速化](https://github.com/mikoto2000/webauditJ/blob/v2.0.2/docs/analysis-performance.md)を参照してください。単一環境の合成ログ測定で、GeoIP・gzip・bundle出力全体は未計測です。Go版の倍率とは測定条件が異なります。

## 互換性と配布

Java 25以上が必要です。従来CLI・レポート・watchの動作と検出の最終判定を維持します。ルール版は`2026.11.20.2`です。公開サンプルは生成時点のスナップショットを保持します。

依存ライブラリ・ルール・テンプレート・ライセンスを含む実行可能`webauditJ.jar`を配布します。GeoIP DBやテスト用期待値は含みません。
