# WebAuditJ v2.2.0

報告書を読み始めてから、対象を選んだ追加調査と結果報告まで進めやすくするマイナーリリースです。

## 変更点

- 幹部向け冒頭を「何が見つかったか・被害は出ているか・次に何をするか」の3項目で整理し、リスクの種類と確認対象へ案内します。
- 技術者向けを5章と付録に整理し、第6章で追加調査の依頼と結果報告を扱います。各対象の観測事実・疑い・未確認事項・次の確認を読み進められます。
- 幹部向け上位10対象と技術的根拠を事案ID、独立検出ではエンジンとルールIDで対応付けます。同じリスク名だけで関連付けません。
- 個別対象のリンクから調査依頼を作成でき、再読込でも選択を維持します。対象IDが不正な場合は別対象の依頼へ置き換えません。
- 対応を強める条件を共通条件と種類別の条件に分け、`webaudit/response-rules-2` としてHTML・JSON・CSVで共有します。
- 不審・関連アクセスCSVは分類・時刻・アクセス情報を先に、追跡用IDを後方に配置します。
- 日本語・英語の合成レポート例をGitHub Pagesで公開し、READMEから参照できます。成果物のハッシュとローカルリンクを検証して公開します。

## 互換性

CSVの列順が変わるため、利用側では列名で読み取ってください。列名と証拠IDは維持します。判断支援JSONには共通の対応条件などのフィールドを追加します。

検出ルール版は `2026.11.20.2` です。攻撃の検出・成否判定の条件を、報告書の表示上の改善で変更しません。アクセスログだけで侵害や被害を確定しない制約と、オフライン動作を維持します。

公開サンプルは生成時点のスナップショットを保持します。

[レポート例を見る](https://mikoto2000.github.io/webauditJ/)

## 配布

Java 25以上で動作する実行可能 `webauditJ.jar` を配布します。依存ライブラリ・ルール・テンプレート・ライセンスを含み、GeoIP DBとテスト用期待値は含みません。
