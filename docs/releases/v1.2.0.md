# WebAuditJ v1.2.0

Go 版 WebAudit main `a26ee0ff1e1bb3d5c88979cf6c0854898f3e5459` の追加機能と修正を Java 版へ移植しました。

## 追加機能

- 攻撃・検出の種類ごとに、成否が不明な理由、調査先、成功・失敗を裏付ける証拠の例を表示します。HTML と端末の上位 5 事案、JSON の `outcome.investigation`、CSV の `details_json` に含みます。
- HTML レポートの既定言語を日本語にしました。`--lang ja` / `--lang en` で選択できます。言語指定は HTML にだけ適用し、証拠ログ・JSON・CSV・端末要約の内容を翻訳しません。

追加調査ガイドは証拠を探す目安で、成否判定の自動更新や侵害の確定を行うものではありません。既存の検知スコア・成否判定は維持しています。

## 修正

- Aura 集約は上限到達後も既存項目を更新し、新規項目だけを共通の上限で制限します。
- GeoIP の起動時警告と検索中の失敗を区別し、起動時警告だけで部分解析にしないようにしました。
- 端末出力から全 Unicode Bidi_Control を除去します。
- レポートの書き込み・close に失敗した場合は不完全なファイルを削除します。完成後に端末要約の出力が失敗しても、完成済みレポートは保持します。

## 実行方法

Java 25 以上が必要です。添付の `webauditJ.jar` は依存ライブラリ・ルール・HTML テンプレートを含む実行可能 JAR です。

```sh
java -jar webauditJ.jar access.log -o report-ja.html
java -jar webauditJ.jar access.log --lang en -o report-en.html
java -jar webauditJ.jar --version
```

通常の解析はオフラインで動作します。GeoIP データベースは別途用意してください。

## 検証

Windows / OpenJDK 25 で全 2,823 テストと JAR 検査を実行し、日英 HTML・JSON・CSV の実行も確認しました。リリースワークフローでも Linux 上の全テスト、JAR 検査、通常解析の通信禁止検証を実行してから公開します。
