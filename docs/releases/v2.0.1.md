# WebAuditJ v2.0.1

Go版で実装した調査報告書の出力と解析進捗表示をJavaへ移植したパッチリリースです。

## 変更点

- `--report-dir`で11章構成の日英HTML、共通JSON、全件CSV別紙、manifestを新規ディレクトリへ生成します。調査名・対象・背景・目的・担当者の任意metadataに対応します。
- 事案と独立したHub/Aura検出の一覧・詳細・戻りリンク、生ログ代表例、事実・推定・未知・条件付き影響、既存調査案内に基づく推奨対応を表示します。従来HTMLの一覧と生ログ参照も改善しました。
- 全不審・関連リクエストを元file/lineとIDへ関連付け、複数ルール・エンジンの重なりを開示します。直接検出と集計への関連を区別します。
- 全アクセス・不審アクセスの統計・時系列・利用可能な国/ASN、41観点と全既存ルールのカバレッジを出力します。0/欠損/不正、無検出/未対応/評価不能/未実施、全件数と不審件数の品質を区別します。
- 原本bytesの前後SHA-256、入力別診断、実効設定・ルール・DB来歴、配布JAR自身と成果物のSHA-256を記録します。証跡・出力上限、INCOMPLETE marker、private spool削除を実装しました。
- 一般的な秘密値のマスク、制御文字の可視化、HTML escape、CSV数式対策を適用します。
- `--verbose`で処理中ファイルと読み取り進捗を標準エラーへ表示します。標準出力のレポート形式は維持します。
- 日英サンプル・出力仕様・要求対応表・性能/メモリ/ディスク実測を追加しました。同一入力のGo/Java間の集計と参照を照合し、配布JAR・オフライン・全artifact hashの検証を拡張しました。

```sh
java -jar webauditJ.jar access.log access.log.1.gz --report-dir report-ja --lang ja --system-name "対象システム"
java -jar webauditJ.jar access.log --report-dir report-en --lang en --verbose
```

## 互換性と制限

Java 25以上が必要です。従来CLI・単一HTML/JSON/CSV・watch・成否判定を維持し、新たな依存ライブラリは追加していません。`--report-dir`は既存出力先を上書きせず、`-o`/`--format`と排他です。ルール版は`2026.11.20.2`のままです。公開サンプルは生成時点のバージョン・環境を記録したスナップショットです。

本文専用攻撃・IP reputation等は未対応、未校正の検出確度はunknownです。アクセスログだけで侵入成否を確定せず、秘密マスクは全個人情報の匿名化を保証しません。容量・保持上限による部分解析と下限件数を明示します。ブラウザ目視は環境制限により未実施で、章・全リンク・escape・hashを自動検証しています。

[出力仕様](https://github.com/mikoto2000/webauditJ/blob/v2.0.1/docs/reporting/output.md)、[要求・テスト・PR対応表](https://github.com/mikoto2000/webauditJ/blob/v2.0.1/docs/reporting/traceability.md)、[資源測定](https://github.com/mikoto2000/webauditJ/blob/v2.0.1/docs/reporting/performance.md)を参照してください。

依存ライブラリ・ルール・HTMLテンプレート・ライセンスを含む実行可能`webauditJ.jar`を配布します。製品JARにGeoIP DBやテスト用期待値は含みません。
