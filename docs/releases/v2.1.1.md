# WebAuditJ v2.1.1

Go版のレビュー修正を移植し、HTMLの判定指標と解析範囲を読み取りやすくしました。

- 攻撃スコアと成否の確信度の凡例を追加し、確信度が成功確率ではないことを明記しました。
- 冒頭にHub・Aura別の件数と警告へのリンクを追加しました。WebAuditの事案件数を含め、異なる集計単位の件数は合算できません。
- タイムゾーン不明の事案ではUTC換算不可と明記し、保持された証拠の時刻へ案内します。
- READMEの継続監視手順を独立した節へ移動し、端末の調査案内の言語を明記しました。

日英HTMLへ適用します。検出ルール・判定条件・機械可読レポートの形式は維持します。Java 25以上で動作する実行可能JARを配布します。
