# WebAuditJ v2.3.0

HTMLの読み方と共有方法を統一するマイナーリリースです。Go版のレポート出力改善をJava版にも移植しました。

## 変更点

- レポート一式の従来の `report.html` を廃止し、幹部向け `executive-summary.html` と技術者向け `technical-report.html` の2種類に統一します。`index.html` から開けます。
- `-o report.html` / `--format html` は、一式と同じ解析処理・技術者向け画面を使います。二次調査プロンプト生成スクリプトとCSV・JSON・仕様書等の参照資料を内蔵し、単一HTMLでオフライン閲覧・対象選択・依頼文生成・資料保存ができます。
- 単一HTMLにも機密値マスク、調査メタデータ、`--include-sensitive-evidence`、`--max-spool-bytes`、`--max-report-bytes` を適用します。CSPハッシュはブラウザーの改行正規化に合わせます。
- 単一HTML例と説明書を更新し、日英の一式サンプルから廃止ファイルを除き、成果物ハッシュとローカルリンクを検証します。

## 互換性と利用時の注意

一式の `report.html` を参照する連携は `technical-report.html` へ変更してください。CLIの `-o report.html` というファイル名指定は引き続き利用できます。技術者向けの単一HTMLにはスクリプトが含まれます。

単独JSON/CSV/端末要約/watchと検出・成否判定の条件は維持します。ルール版は `2026.11.20.2` です。既存の低水準Reports APIも維持します。

内蔵資料の分だけHTML容量と生成中の一時ディスク使用量が増えます。一時資料は終了時に削除します。幹部向け報告とフォルダーで引き継ぐ資料は `--report-dir` で出力してください。既定の機密値マスクは全個人情報の匿名化を保証しません。

公開サンプルは生成時点の解析・版情報を保持するスナップショットです。実ブラウザーの表示・印刷確認は未実施で、日英の構造・リンク・CSP・実スクリプト操作を自動検証しています。

[レポート例を見る](https://mikoto2000.github.io/webauditJ/)

## 配布

Java 25以上で動作する実行可能 `webauditJ.jar` を配布します。依存ライブラリ・ルール・テンプレート・ライセンスを含み、GeoIP DBとテスト用期待値は含みません。
