# WebAuditJ v2.0.0

Go WebAudit v2.0.0 の監視機能を Java 版へ移植しました。

- `watch INPUT...` でアクセスログを継続監視。部分行、複数ファイル、非再帰ディレクトリ、rename / copytruncate に対応。
- ネイティブ検知・時間窓分析・事案の相関・成否推定を再利用し、created / updated / closed を安定 ID・revision・sequence 付き JSONL schema 1 で出力。
- ファイル ID・オフセット・部分行・事案・通知履歴のチェックポイント保存と復元。`--no-state` / `--reset-state`、OS ロック、チェックサム、原子的保存に対応。
- シェルを介さない外部コマンド Hook。イベント JSON の stdin、重要度・変更種別フィルタ、重複抑制、キュー・並列数・タイムアウト、Windows Job Object / Unix process group による子孫終了に対応。
- ローカル MMDB と既存キャッシュによる任意の GeoIP / ASN 補足。通常監視でダウンロード・外部 API 照会は行いません。
- 通知サンプル、JSON Schema、Go 版参照データ、実プロセス統合テスト、測定ハーネスを追加。

```sh
java -jar target/webauditJ.jar watch access.log
java -jar target/webauditJ.jar watch access.log --from beginning --format jsonl
java -jar target/webauditJ.jar watch access.log --on-detect ./examples/notify.sh
```

初回は EOF から開始し、保存状態があれば優先して復元します。Ctrl+C で状態保存・Hook 停止を行います。従来のバッチ CLI、HTML / JSON / CSV、GeoIP 管理は維持しています。

Java 25 以上が必要です。チェックポイント形式と保存先は Java 版専用です。Hook の補助 JVM 起動もタイムアウトに含みます。

利用方法と制限は [監視・Hookガイド](../watch.md)、検証範囲は [移植検証記録](../watch-validation.md) を参照してください。
