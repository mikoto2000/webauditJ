# WebAuditJ v2.1.0

アクセスログの一次調査結果を、幹部向け・技術者向けの報告と二次調査の依頼準備へつなぐマイナーリリースです。

## 変更点

- `--report-dir` で `executive-summary.html`、`technical-report.html`、入口となる `index.html` を同時出力します。幹部向けには対応方針・条件付きリスク・承認事項・アクション・判断条件を、技術者向けには既存の詳細・証拠と調査計画を表示します。
- 共通モデルから判断・調査計画JSON、リスク台帳・アクションCSV、全体・高優先度・個別事案の二次調査依頼Markdownを生成します。
- 技術者向けHTMLで対象事案と3つのフォルダーを指定し、依頼文をコピー・保存できます。ファイル読み取り・資料収集・外部送信・LLM呼び出し・調査実行は行いません。
- 二次・三次調査へ報告構成と品質要件を引き継ぐ `report-spec.md` とHTML/CSSテンプレートを出力します。日本語・英語に対応します。
- 既存の検出・成否・証拠IDを保持し、独立エンジン検出の優先度・成否は未評価として区別します。ログ由来値を作業指示へ直接埋め込まず、機密値マスク・HTML/CSV安全表示・出力上限・manifestハッシュ管理を引き継ぎます。
- レポート出力先の親ディレクトリがない場合に作成するよう修正しました。入力と出力の重複検査・既存出力の上書き禁止は維持します。

詳細は[幹部・技術者向けレポート](https://github.com/mikoto2000/webauditJ/blob/v2.1.0/docs/reporting/audience-reports.md)を参照してください。

## 互換性と制限

既存CLI・単一形式レポート・watchの動作を維持します。従来の `report.html` はスクリプトなしの技術報告として、新しい成果物へのリンクを表示します。公開サンプルは生成時点のスナップショットを保持します。ルール版は `2026.11.20.2` です。

HTTPステータスだけで認証成功・侵害・被害を確定しません。調査優先度は組織固有の重大度や成功確率ではなく、監視継続も安全の保証ではありません。実際の印刷/PDF表示と百万行規模の性能は未検証です。

## 配布

Java 25以上が必要です。依存ライブラリ・ルール・テンプレート・ライセンスを含む実行可能 `webauditJ.jar` を配布します。GeoIP DBやテスト用期待値は含みません。
